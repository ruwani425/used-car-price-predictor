# Frontend Web Client

React single-page application built with Vite and Material-UI for vehicle valuation, car comparison, and depreciation curve visualizations.

---

## Features

- **Valuation Calculator**: Input form with dynamic cascading brand/model options.
- **5-Year Depreciation Chart**: Visual forecast of vehicle depreciation.
- **Side-by-Side Car Comparison**: Compare prices and specs of two cars.
- **Multi-Currency Toggle**: Instant price display in LKR, USD, EUR, GBP, or JPY.
- **Recent History**: Quick access to recent predictions.

---

## Setup & Run

### 1. Install Dependencies
```bash
npm install
```

### 2. Environment Variables (`.env`)
```env
VITE_API_BASE_URL=http://localhost:5000
```

### 3. Start Development Server
```bash
npm run dev
```
Open: `http://localhost:5173`

### 4. Build for Production
```bash
npm run build
```
